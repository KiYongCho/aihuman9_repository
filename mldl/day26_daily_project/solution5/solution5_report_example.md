# Team 5 강사용 보고서 작성 예시

## 프로젝트
다음 시점 전력수요 예측

## 문제 유형
회귀

## 핵심 모델
RNN/LSTM

## 예시 결론
최근 24개 시점의 전력수요와 기온을 이용하여 다음 시점의 전력수요를 예측했습니다. 시계열 데이터이므로 무작위 분리 대신 앞쪽 구간을 학습, 뒤쪽 구간을 테스트로 사용했습니다. SimpleRNN과 LSTM을 같은 조건으로 비교하고 Dense(1) Linear 출력과 MSE 손실을 적용했습니다. MAE와 RMSE로 예측 오차를 원래 전력수요 단위에서 해석했습니다. 실제값과 예측값 선그래프를 통해 모델이 시간 흐름의 추세를 얼마나 따라가는지 확인했습니다.

> 실제 수치는 학생의 TensorFlow 버전, 난수 상태, 학습 환경에 따라 달라질 수 있으므로
> 특정 숫자를 정답으로 평가하기보다 학습 과정과 해석을 중심으로 확인하는 것을 권장합니다.
