## 2. 기술적으로 설명할 수 있는 내용
- 사용한 핵심 기술 및 선택 이유:
  - Edge-TTS
    - 텍스트를 자연스러운 한국어 음성으로 변환 및 다양한 음성 제공
  - Faster-Whisper를 활용한 음성 인식
    - 한국어 음성을 텍스트로 변환하고, CPU 환경에서도 실행하기 위함
  - TF-IDF와 LinearSVC를 활용하여 사용자의 명령 의도를 분류
    - 사용자 명령을 벡터화하고 9가지 의도로 분류
  - Streamlit을 활용한 웹 UI
    - Python만으로 웹 UI를 간편하게 구현하기 위함
  - PostgreSQL을 활용한 데이터 저장 기능을 구현
    - 할 일, 메모, 처리 이력을 지속적으로 저장하고 관리
- 가장 어려웠던 문제와 원인: 
  - 음성 인식 과정에서 띄어쓰기나 단어가 잘못 인식되는 문제가 있었고, 자연어 명령을 분석하는 과정에서 날짜나 제목이 정확하게 추출되지 않는 경우가 있었음
  - 여러 기능을 연동하면서 코드 오류가 발생
- 직접 구현한 해결 과정: 
  - 음성 데이터의 형식과 품질을 검사하고, 16kHz 모노 변환과 무음 제거 등의 전처리 기능을 적용
  - STT 인식 오류를 개선하기 위해 Beam Size별 WER, CER, RTF를 비교하여 적절한 설정을 선택
- STT/TTS 파이프라인 이해 내용: 
  - STT
    - 사용자의 음성을 입력받아 전처리한 후 Faster-Whisper 모델을 통해 텍스트로 변환하는 과정
    - 변환된 텍스트는 의도 분류와 데이터베이스 처리를 거쳐 결과를 생성
  - TTS 
    - 생성된 응답 텍스트를 Edge-TTS를 통해 음성으로 변환하여 사용자에게 전달하는 과정
    - 음성 데이터의 품질과 모델 설정이 인식 결과 및 처리 속도에 영향을 준다는 것을 이해
