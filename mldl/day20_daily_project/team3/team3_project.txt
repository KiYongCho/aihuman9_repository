20일차 머신러닝 미니프로젝트 - Team 3
============================================================

[프로젝트 주제]
대출 승인 예측

[프로젝트 유형]
분류(Classification)

[업무 목적]
신청 특성을 바탕으로 승인 가능성을 예측하는 모델을 비교합니다. 교육용 가상 데이터이며 실제 금융심사에 사용하지 않습니다.

[데이터 안내]
- 파일명: team3_data.csv
- 행 수: 750개
- 데이터는 수업용으로 설계한 실무형 가상 데이터입니다.
- 일부 특성에는 소량의 결측치가 포함되어 있습니다.
- 개인정보나 실제 고객/금융/부동산 정보를 포함하지 않습니다.

[컬럼 설명]
- 연소득_만원: 연간 소득(만원)
- 신용점수: 신용 점수
- 부채비율: 소득 대비 부채 비율(%)
- 재직년수: 현재 직장의 재직 기간
- 대출신청액_만원: 신청한 대출 금액(만원)
- 기존대출수: 현재 보유한 기존 대출 건수
- 연체횟수: 최근 연체 횟수
- 담보가치_만원: 담보 평가 금액(만원)
- 승인여부: 예측 대상: 승인 여부(1/0)

[팀 운영]
- 2인 1조로 진행합니다.
- 1명은 데이터 확인/전처리/시각화를 먼저 담당합니다.
- 다른 1명은 모델 구현/평가/보고서 작성을 먼저 담당합니다.
- 중간에 반드시 역할을 바꾸고, 최종 결과는 두 명 모두 설명할 수 있어야 합니다.

[완료 목표]
짧은 시간 안에 아래 머신러닝 전체 흐름을 한 번 완성하는 것이 목표입니다.

데이터 확인
→ 결측치 처리
→ X / y 정의
→ 학습/테스트 데이터 분리
→ 여러 모델 학습
→ 모델 평가 및 비교
→ 최종 모델 선택
→ 시각화
→ 결과 해석 및 보고서 작성

[필수 작업]

1. pandas로 CSV 파일을 읽습니다.

2. 다음 내용을 확인합니다.
   - 데이터 행/열 개수
   - 컬럼명
   - 자료형
   - 결측치 개수
   - 기초 통계량

3. 결측치를 처리합니다.
   - 숫자형 컬럼의 결측치는 중앙값(median)을 권장합니다.
   - 왜 중앙값을 선택했는지 보고서에 1~2줄로 설명합니다.

4. 입력 특성 X와 정답 y를 정의합니다.
   - Target: 승인여부

5. train_test_split()으로 학습 데이터와 테스트 데이터를 나눕니다.
   - test_size=0.25
   - random_state=42
   - 분류 프로젝트는 가능하면 stratify=y를 사용합니다.

6. 아래 모델 중 최소 3개 이상을 학습하고 비교합니다.
- LogisticRegression
- KNeighborsClassifier
- DecisionTreeClassifier
- RandomForestClassifier

7. 모델별 성능을 표 형태로 정리합니다.

[평가 지표]
- Accuracy(정확도)
- Precision(정밀도)
- Recall(재현율)
- F1-score
- Confusion Matrix(혼동행렬)

8. 다음 시각화를 작성합니다.
1) 타깃 클래스 분포 그래프
2) 모델별 F1-score 비교 막대그래프
3) 최종 모델의 혼동행렬
4) 랜덤포레스트 특성 중요도 그래프

9. 최종 모델 하나를 선택하고 다음 내용을 작성합니다.
   - 어떤 모델을 선택했는가?
   - 어떤 평가 지표를 근거로 선택했는가?
   - 중요한 특성은 무엇이었는가?
   - 실제 업무에서는 어떻게 활용할 수 있는가?
   - 이 모델의 한계는 무엇인가?

10. team3_report_template.md 파일을 복사하여 보고서를 완성합니다.

[시간이 부족할 때 우선순위]
1순위: 데이터 확인 + 전처리
2순위: 모델 3개 비교
3순위: 핵심 그래프 3개 이상
4순위: 보고서 결론 5줄 이상

- 왜 이 모델을 선택했는지 설명하는 것이 더 중요합니다.
- 결측치 처리나 스케일링을 학습했다면 적절히 적용해도 됩니다.
- 새로운 라이브러리를 과도하게 추가하지 말고 pandas, matplotlib, scikit-learn 중심으로 진행하세요.
