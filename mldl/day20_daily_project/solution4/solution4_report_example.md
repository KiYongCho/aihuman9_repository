# Team 4 강사용 보고서 예시

## 1. 프로젝트 개요
- 주제: 자전거 대여량 예측
- 유형: 회귀
- 목적: 날씨와 시간 특성을 이용하여 예상 대여 수요를 예측하고 자전거 배치에 활용합니다.

## 2. 데이터 전처리
- 타깃: `대여량`
- 입력 특성: 타깃을 제외한 전체 수치형 특성
- 결측치: 각 특성의 중앙값으로 대체
- 학습/테스트: 75% / 25%
- random_state: 42

## 3. 모델 비교 결과

| 모델             |     MAE |    RMSE |     R2 |
|:-----------------|--------:|--------:|-------:|
| RandomForest     | 156.248 | 216.111 | 0.8741 |
| LinearRegression | 210.343 | 261.549 | 0.8156 |
| DecisionTree     | 186.47  | 267.335 | 0.8074 |

## 4. 주요 특성
RandomForest 기준 상위 특성:
- 기온: 0.7529
- 출퇴근시간여부: 0.0984
- 강수량: 0.0489
- 습도: 0.0319
- 일조시간: 0.0283

## 5. 최종 결론 예시
자전거 대여량 예측 문제를 회귀 모델로 해결했습니다. LinearRegression, DecisionTree, RandomForest를 비교했으며 예시 실행에서는 RandomForest의 R²가 0.8741로 가장 높았습니다. RandomForest 기준 중요 특성으로는 기온, 출퇴근시간여부, 강수량 등이 확인되었습니다. 실제 적용 시에는 평균 오차뿐 아니라 큰 오차 사례와 데이터 범위 밖 예측의 위험도 함께 확인해야 합니다.
