# Team 3 강사용 보고서 예시

## 1. 프로젝트 개요
- 주제: 대출 승인 예측
- 유형: 분류
- 목적: 신청 특성을 바탕으로 승인 가능성을 예측하는 모델을 비교합니다. 교육용 가상 데이터이며 실제 금융심사에 사용하지 않습니다.

## 2. 데이터 전처리
- 타깃: `승인여부`
- 입력 특성: 타깃을 제외한 전체 수치형 특성
- 결측치: 각 특성의 중앙값으로 대체
- 학습/테스트: 75% / 25%
- random_state: 42

## 3. 모델 비교 결과

| 모델               |   Accuracy |   Precision |   Recall |     F1 |
|:-------------------|-----------:|------------:|---------:|-------:|
| LogisticRegression |     0.7872 |      0.7667 |   0.6389 | 0.697  |
| KNN                |     0.7553 |      0.7031 |   0.625  | 0.6618 |
| RandomForest       |     0.7553 |      0.7097 |   0.6111 | 0.6567 |
| DecisionTree       |     0.7021 |      0.6739 |   0.4306 | 0.5254 |

## 4. 주요 특성
RandomForest 기준 상위 특성:
- 신용점수: 0.2670
- 부채비율: 0.1656
- 대출신청액_만원: 0.1497
- 재직년수: 0.1248
- 연소득_만원: 0.1153

## 5. 최종 결론 예시
대출 승인 예측 문제를 분류 모델로 해결했습니다. LogisticRegression, KNN, DecisionTree, RandomForest를 비교했으며 예시 실행에서는 LogisticRegression의 F1-score가 0.6970로 가장 높았습니다. RandomForest 기준 중요 특성으로는 신용점수, 부채비율, 대출신청액_만원 등이 확인되었습니다. 실제 적용 시에는 예측 오류, 특히 거짓 양성/거짓 음성이 업무에 미치는 영향을 함께 고려해야 합니다.

> 학생이 전처리 방법, 하이퍼파라미터 등을 바꾸면 결과가 달라질 수 있습니다.
