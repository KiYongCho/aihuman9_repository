# AI 모델·알고리즘 실험 및 성능 평가 보고서

## 1. 목적 및 가설
- **평가할 기능**: 한국어 음성 비서 NLU 의도 분류(Intent Classification) 모델 및 슬롯 추출 알고리즘
- **가설**: 일상 대화처럼 말이 짧고 조사가 자주 생략되는 한국어 음성 명령 환경에서는, 단순 확률 기반 모델(로지스틱 회귀)보다 문장 간의 결정 경계를 확실하게 구분하는 **선형 서포트 벡터 머신(LinearSVC)**이 더 높은 분류 정확도(95% 이상)와 안정적인 F1 점수를 달성할 것이다.
- **성공 판단 기준**:
  - 안내서 필수 요구사항(최소 5개 의도)을 넘어 확장 9개 의도 전체 대상 Test Accuracy ≥ 95.0% 달성
  - 클래스별 불균형 없는 균형 잡힌 성능 확보 (Macro F1-Score ≥ 0.9500)
  - 실시간 음성 비서 상호작용을 위한 단일 문장 NLU 추론 지연 시간(Latency) 50ms 이내 보장

## 3. 데이터 분리 및 평가 방법
- **학습·검증·테스트 분리 방법**:
  - 전체 180건 데이터를 9개 의도(`ADD_TASK`, `UPDATE_TASK`, `COMPLETE_TASK`, `DELETE_TASK`, `LIST_TASK`, `ADD_MEMO`, `DELETE_MEMO`, `LIST_MEMO`, `HELP`)별로 계층화 분할(Stratified Split, 8:2 비율)
  - Train: 80% (144건, 각 의도별 16건)
  - Test: 20% (36건, 각 의도별 4건)
- **테스트 데이터 수·선정 방식**: 총 36건, 특정 의도에 편향되지 않도록 모든 의도 클래스에서 4건씩 무작위 균등 추출 (`random_state=42`)
- **정답 라벨 작성 방법**: 음성 비서 도메인 발화 시나리오를 기반으로 팀원 전원의 상호 교차 검증을 거친 9개 표준 의도 단일 라벨링 적용
- **동일 데이터 재사용·누수 여부**:
  - `commands_RE.csv` 내 중복 문장 완전 제거 및 SHA-256 해시 검증 완료
  - Train과 Test 데이터셋 간 문장 완전 격리로 Data Leakage(데이터 누수) 없음
- **안내서 지침 준수 (추론 점수 체계)**:
  - 의도 추론 함수(`predict_intent`)에서 `LogisticRegression`은 `probability`(확률), `LinearSVC`는 `decision_score`(결정 점수)로 구분하여 신뢰도 메타데이터 반환 규격 준수

## 6. 한계·후속 개선
- **소규모 데이터셋 한계**: 180건의 규칙 기반 데이터셋으로 학습되어, 어휘 변형이 극단적이거나 긴 복합 문장의 경우 일반화 성능 저하 가능성이 존재함.
- **하이브리드 NLU 고도화**: 머신러닝 모델의 단점을 보완하기 위해 `src/core.py`에 규칙 기반(Rule-based) 후처리 보정 엔진을 결합하여 실서비스 결함을 원천 차단함.
- **후속 개선 방향**:
  1. 사전 학습된 한국어 경량 언어 모델(KoELECTRA 또는 On-device SLM) 도입 검토
  2. 한글 수사(예: "이십구일" → "29일") 및 구어체 메모 어미("회의준비 메모", "메모 추가 회의준비") 슬롯 추출 정규식 패턴의 지속적 확장
