# Team 5 강사용 보고서 예시

## 1. 프로젝트 개요
- 주제: 아파트 매매가격 예측
- 유형: 회귀
- 목적: 주거 특성을 이용하여 매매가격을 예측하고 어떤 특성이 가격과 관련되는지 해석합니다.

## 2. 데이터 전처리
- 타깃: `매매가격_만원`
- 입력 특성: 타깃을 제외한 전체 수치형 특성
- 결측치: 각 특성의 중앙값으로 대체
- 학습/테스트: 75% / 25%
- random_state: 42

## 3. 모델 비교 결과

| 모델             |      MAE |     RMSE |     R2 |
|:-----------------|---------:|---------:|-------:|
| LinearRegression |  7128.54 |  8921.47 | 0.8836 |
| RandomForest     |  8384.62 | 10515.8  | 0.8383 |
| DecisionTree     | 12504.3  | 15585.7  | 0.6447 |

## 4. 주요 특성
RandomForest 기준 상위 특성:
- 전용면적: 0.6888
- 학군점수: 0.0909
- 건축연수: 0.0509
- 도심거리_km: 0.0454
- 역거리_m: 0.0440

## 5. 최종 결론 예시
아파트 매매가격 예측 문제를 회귀 모델로 해결했습니다. LinearRegression, DecisionTree, RandomForest를 비교했으며 예시 실행에서는 LinearRegression의 R²가 0.8836로 가장 높았습니다. RandomForest 기준 중요 특성으로는 전용면적, 학군점수, 건축연수 등이 확인되었습니다. 실제 적용 시에는 평균 오차뿐 아니라 큰 오차 사례와 데이터 범위 밖 예측의 위험도 함께 확인해야 합니다.
