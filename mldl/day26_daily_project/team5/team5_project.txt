AI휴먼 데일리 딥러닝 미니프로젝트 - Team 5
=======================================================

[프로젝트]
다음 시점 전력수요 예측

[문제 유형]
회귀

[핵심 모델]
RNN/LSTM

[프로젝트 설명]
최근 24개 시점의 전력수요와 기온을 이용하여 다음 시점의 수요를 예측합니다.

[이번 프로젝트에서 반드시 확인할 개념]
- 입력 shape=(24, 2)의 의미 설명
- SimpleRNN과 LSTM 회귀 모델 비교
- Linear 출력층과 MSE 손실 함수 사용
- EarlyStopping으로 실제 수행 Epoch 확인
- 실제값과 예측값 그래프 및 MAE/RMSE 해석

[데이터]
- 파일명: team5_data.npz
- 수업용으로 생성한 가상 데이터입니다.
- 실제 개인정보나 민감 데이터를 포함하지 않습니다.
- 외부 다운로드 없이 바로 실습할 수 있습니다.

[필수 작업]
1. np.load()로 X와 y를 읽고 shape를 확인합니다.
2. 입력 (24, 2)가 24개 시점 × 2개 특성이라는 점을 설명합니다.
3. 시간 순서를 유지한 상태로 앞 80%를 학습, 뒤 20%를 테스트로 사용합니다.
4. 학습 데이터 기준으로 특성 스케일을 조정합니다.
5. SimpleRNN(32) 회귀 모델을 구성합니다.
6. LSTM(32) 회귀 모델을 구성합니다.
7. 두 모델 모두 Dense(1), Adam, mse를 사용합니다.
8. EarlyStopping을 동일하게 적용합니다.
9. MAE, RMSE, 실제 수행 Epoch 수를 비교합니다.
10. 테스트 구간의 실제값과 예측값을 선그래프로 시각화합니다.

[보고서]
`team5_report_template.md` 파일을 복사하여 결과를 작성하세요.

[필수 시각화]
- 학습곡선: train loss / validation loss
- 문제 유형에 맞는 성능 시각화
- 데이터 또는 예측 결과를 설명할 수 있는 그래프 1개 이상

[시간이 부족할 때]
1순위: 데이터 shape 이해
2순위: 모델 구성과 학습
3순위: EarlyStopping + History 확인
4순위: 최종 성능과 그래프
5순위: 보고서 결론 작성

[주의]
- Test Set을 반복적으로 보면서 모델을 수정하지 않습니다.
- StandardScaler를 사용할 때는 Training Set에만 fit합니다.
- 모델 이름보다 데이터 shape와 문제 유형에 맞는 구조를 선택하는 것이 중요합니다.
