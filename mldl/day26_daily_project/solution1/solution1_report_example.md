# Team 1 강사용 보고서 작성 예시

## 프로젝트
회원 재방문 예측

## 문제 유형
이진 분류

## 핵심 모델
Dense

## 예시 결론
Dense 이진 분류 구조를 이용하여 회원의 재방문 여부를 예측했습니다. 일반 표형 데이터이므로 CNN이나 RNN보다 Dense 구조가 적합합니다. ReLU 은닉층과 Sigmoid 출력층을 사용하고 Binary Crossentropy로 학습했습니다. 기본 모델과 Dropout 모델의 validation loss를 비교해 과적합 여부를 확인했습니다. EarlyStopping을 이용하여 검증 손실이 개선되지 않을 때 자동으로 학습을 종료했습니다. 실제 적용 시에는 재방문 가능성이 낮은 고객을 대상으로 리텐션 활동을 설계할 수 있습니다.

> 실제 수치는 학생의 TensorFlow 버전, 난수 상태, 학습 환경에 따라 달라질 수 있으므로
> 특정 숫자를 정답으로 평가하기보다 학습 과정과 해석을 중심으로 확인하는 것을 권장합니다.
