20일차 머신러닝 미니프로젝트 - Team 5
============================================================

[프로젝트 주제]
아파트 매매가격 예측

[프로젝트 유형]
회귀(Regression)

[업무 목적]
주거 특성을 이용하여 매매가격을 예측하고 어떤 특성이 가격과 관련되는지 해석합니다.

[데이터 안내]
- 파일명: team5_data.csv
- 행 수: 800개
- 데이터는 수업용으로 설계한 실무형 가상 데이터입니다.
- 일부 특성에는 소량의 결측치가 포함되어 있습니다.
- 개인정보나 실제 고객/금융/부동산 정보를 포함하지 않습니다.

[컬럼 설명]
- 전용면적: 전용면적(㎡)
- 역거리_m: 가까운 역까지 거리(m)
- 건축연수: 준공 후 경과 연수
- 층: 거래 층
- 학군점수: 교육용으로 만든 학군 지표(40~100)
- 편의시설수: 주변 편의시설 개수
- 세대당주차대수: 세대당 주차 가능 대수
- 도심거리_km: 도심까지 거리(km)
- 매매가격_만원: 예측 대상: 매매가격(만원)

[팀 운영]
- 2인 1조로 진행합니다.
- 1명은 데이터 확인/전처리/시각화를 먼저 담당합니다.
- 다른 1명은 모델 구현/평가/보고서 작성을 먼저 담당합니다.
- 중간에 반드시 역할을 바꾸고, 최종 결과는 두 명 모두 설명할 수 있어야 합니다.

[완료 목표]
짧은 시간 안에 아래 머신러닝 전체 흐름을 한 번 완성하는 것이 목표입니다.

데이터 확인
→ 결측치 처리
→ X / y 정의
→ 학습/테스트 데이터 분리
→ 여러 모델 학습
→ 모델 평가 및 비교
→ 최종 모델 선택
→ 시각화
→ 결과 해석 및 보고서 작성

[필수 작업]

1. pandas로 CSV 파일을 읽습니다.

2. 다음 내용을 확인합니다.
   - 데이터 행/열 개수
   - 컬럼명
   - 자료형
   - 결측치 개수
   - 기초 통계량

3. 결측치를 처리합니다.
   - 숫자형 컬럼의 결측치는 중앙값(median)을 권장합니다.
   - 왜 중앙값을 선택했는지 보고서에 1~2줄로 설명합니다.

4. 입력 특성 X와 정답 y를 정의합니다.
   - Target: 매매가격_만원

5. train_test_split()으로 학습 데이터와 테스트 데이터를 나눕니다.
   - test_size=0.25
   - random_state=42
   

6. 아래 모델 중 최소 3개 이상을 학습하고 비교합니다.
- LinearRegression
- DecisionTreeRegressor
- RandomForestRegressor

7. 모델별 성능을 표 형태로 정리합니다.

[평가 지표]
- MAE
- RMSE
- R²

8. 다음 시각화를 작성합니다.
1) 타깃 값 분포 히스토그램
2) 모델별 MAE 비교 막대그래프
3) 최종 모델의 실제값 vs 예측값 산점도
4) 랜덤포레스트 특성 중요도 그래프

9. 최종 모델 하나를 선택하고 다음 내용을 작성합니다.
   - 어떤 모델을 선택했는가?
   - 어떤 평가 지표를 근거로 선택했는가?
   - 중요한 특성은 무엇이었는가?
   - 실제 업무에서는 어떻게 활용할 수 있는가?
   - 이 모델의 한계는 무엇인가?

10. team5_report_template.md 파일을 복사하여 보고서를 완성합니다.
