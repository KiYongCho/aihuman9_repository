# Team 2 강사용 보고서 작성 예시

## 프로젝트
배송 소요시간 예측

## 문제 유형
회귀

## 핵심 모델
Dense

## 예시 결론
배송 거리, 출고 대기시간, 교통 혼잡도 등의 특성을 이용하여 배송 소요시간을 회귀 방식으로 예측했습니다. 출력층은 연속값을 제한 없이 예측해야 하므로 Dense(1)의 Linear 출력을 사용했습니다. batch_size 16과 64를 비교하여 학습시간, 실제 Epoch 수, MAE와 RMSE를 함께 확인했습니다. Batch Size가 달라지면 한 Epoch에서 가중치가 갱신되는 횟수가 달라집니다. 최종 모델은 MAE와 RMSE가 낮고 validation loss가 안정적인 설정을 기준으로 선택했습니다.

> 실제 수치는 학생의 TensorFlow 버전, 난수 상태, 학습 환경에 따라 달라질 수 있으므로
> 특정 숫자를 정답으로 평가하기보다 학습 과정과 해석을 중심으로 확인하는 것을 권장합니다.
