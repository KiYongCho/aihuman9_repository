# Team 1 강사용 보고서 예시

## 1. 프로젝트 개요
- 주제: 고객 이탈 예측
- 유형: 분류
- 목적: 이탈 가능성이 높은 고객을 사전에 찾아 유지 활동의 우선순위를 정합니다.

## 2. 데이터 전처리
- 타깃: `이탈여부`
- 입력 특성: 타깃을 제외한 전체 수치형 특성
- 결측치: 각 특성의 중앙값으로 대체
- 학습/테스트: 75% / 25%
- random_state: 42

## 3. 모델 비교 결과

| 모델               |   Accuracy |   Precision |   Recall |     F1 |
|:-------------------|-----------:|------------:|---------:|-------:|
| LogisticRegression |     0.7086 |      0.5926 |   0.5246 | 0.5565 |
| KNN                |     0.7029 |      0.5918 |   0.4754 | 0.5273 |
| DecisionTree       |     0.64   |      0.4828 |   0.459  | 0.4706 |
| RandomForest       |     0.6629 |      0.5227 |   0.377  | 0.4381 |

## 4. 주요 특성
RandomForest 기준 상위 특성:
- 가입개월: 0.2162
- 만족도: 0.1855
- 최근로그인경과일: 0.1663
- 월이용금액: 0.1567
- 고객센터문의수: 0.1152

## 5. 최종 결론 예시
고객 이탈 예측 문제를 분류 모델로 해결했습니다. LogisticRegression, KNN, DecisionTree, RandomForest를 비교했으며 예시 실행에서는 LogisticRegression의 F1-score가 0.5565로 가장 높았습니다. RandomForest 기준 중요 특성으로는 가입개월, 만족도, 최근로그인경과일 등이 확인되었습니다. 실제 적용 시에는 예측 오류, 특히 거짓 양성/거짓 음성이 업무에 미치는 영향을 함께 고려해야 합니다.
