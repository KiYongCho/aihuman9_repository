## 2. 권리·동의·라이선스
- **본인 또는 허락받은 음성만 사용**: 팀원 전원(문윤성, 이태규, 엄기훈, 정유아, 최준혁)이 사전에 음성 데이터 수집 및 연구/평가 활용에 동의하였으며, 제3자의 무단 음성은 일체 포함하지 않음.
- **사용 목적과 보관 기간 안내**: 본 프로젝트(한국어 AI 음성 비서) 모델 학습 및 성능 평가, 과제 제출용으로만 제한 사용하며, 평가 및 프로젝트 종료 후 관련 개인 식별 음성은 즉시 파기함.
- **공개 저장소에 원본 음성 업로드 금지**:
  - 개인정보 및 원본 무압축 대용량 음성(Raw Audio)의 공개 유출을 방지하기 위해 비공개(Private) 팀 협업 저장소 내에서만 최소 단위로 관리함.
  - 저장소에 포함된 음성 파일은 개인 식별 정보가 없는 순수 명령 발화로 한정하며, 벤치마크 재현성을 위해 필요한 최소 규격(PCM_16 WAV) 데이터만 버전 관리함.
- **외부 데이터 출처·라이선스**: 외부 상용 데이터셋을 무단 복제하지 않고, 프로젝트 목적에 맞춰 100% 자체 제작한 명령어 및 발화 데이터셋을 사용함.

## 3. 전처리 표준
| 항목 | 기준 | 적용 코드/함수 | 검증 |
|---|---|---|---|
| 채널 | mono (단일 채널) | `src/audio.py` (`y.mean(axis=1)`) | `sf.info` channels == 1 확인 |
| 샘플링레이트 | 16,000Hz (Whisper 모델 표준 입력 규격) | `src/audio.py` (`_resample`, `scipy.signal.resample_poly`) | `TARGET_SR = 16000` 리샘플링 일치 확인 |
| 파일 포맷 | WAV/PCM_16 (16-bit Linear PCM), MP3 디코딩 지원 | `src/audio.py` (`sf.write`, `TARGET_SUBTYPE="PCM_16"`) | 헤더 포맷 및 비트 심도 검증 |
| 무음·길이 | 무음 구간 자동 트리밍, 음성 길이 0.5초 ~ 15.0초 제한 | `src/audio.py` (`_trim_silence`, `TOP_DB=25`, `check_quality`) | 0.5초 미만 / 15초 초과 시 예외 처리 (`ValueError`) |
| 볼륨/RMS | 최소 피크 0.02 이상 유지 | `src/audio.py` (`LOW_PEAK=0.02`, `check_quality()`) | 볼륨 부족 시 경고 및 무음(진폭 < 1e-6) 차단 |
| 클리핑 검사 | 원본에서 abs(sample) >= 0.999인 비율 0.001 초과 시 경고 | `src/audio.py` (`CLIP_RATIO`, `prepare()`, `check_quality()`) | 클리핑 경고 추가 |
| 중복 판정 | 동일 원본 바이트 SHA-256 해시 값, 최근 100개 | `src/audio.py` (`check_recent()`, `preprocess()`) | check_duplicate 값이 True일 경우 차단 |

## 4. 학습·검증·평가 분리
- **분할 단위(문장/화자/녹음 세션)**: 문장 및 의도(Intent) 단위 계층화 분할 (Stratified Split)
- **train/validation/test 비율**:
  - Train: 80% (144건)
  - Test: 20% (36건) - 9개 의도별 각 4건씩 균등 분할
- **동일·유사 문장 누수 방지**:
  - `SHA-256` 해시 기반 중복 입력 검증 로직(`src/audio.py` 내 `check_recent`) 적용
  - Train과 Test 데이터셋 간 문장 완전 분리 및 중복 문장 미포함 확인
- **랜덤 시드**: `random_state=42`로 고정하여 데이터 분할 및 모델 학습 결과의 일관성 보장
