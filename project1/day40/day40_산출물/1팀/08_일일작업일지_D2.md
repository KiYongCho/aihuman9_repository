## 장애·의사결정
| 이슈 | 원인 | 시도한 해결책 | 현재 상태 | 도움 필요 사항 |
|---|---|---|---|---|
| **음원 규격 불일치** | 실 녹음 음원이 48kHz, 2채널로 인입되어 Whisper 입력 규격(16kHz 모노)과 불일치 | `librosa.to_mono`와 `resample`을 결합한 `standardize` 함수를 작성하여 16,000Hz 1채널 PCM_16 WAV로 자동 통일 | 해결 완료 | 없음 |
| **침묵 구간에 따른 지연** | 녹음 시작/종료 시 불필요한 침묵이 최대 1.3초 발생하여 음성 인식 불필요한 지연 유발 | 팀원 아이디어인 `trim_silence`를 도입하여, 앞뒤 0.2초 안전 패딩을 남기고 긴 무음을 자동 절삭 | 해결 완료 | 없음 |
| **중복 음성 파일 유입** | 동일한 파일의 중복 등록 및 중복 처리 가능성 | `hashlib.sha256` 해시를 생성하여 판다스 `drop_duplicates`로 동일 파일 자동 제거 기능 구현 | 해결 완료 | 없음 |
| **팀 개발 시 DB 충돌 위험** | 개발 중 하나의 DB를 공유하면 테이블 초기화나 삭제 테스트 시 상호 간섭 발생 우려 | 개발 단계에서는 팀원 각자의 Neon DB(또는 로컬 DB)를 `.env`에 설정하여 독립 개발 후 최종 배포 시 통합하기로 결정 | 의사결정 완료 | 없음 |
