# Team 2 강사용 보고서 예시

## 1. 프로젝트 개요
- 주제: 제조설비 고장 예측
- 유형: 분류
- 목적: 고장 위험이 높은 설비를 조기에 찾아 예방정비 대상을 선정합니다.

## 2. 데이터 전처리
- 타깃: `고장여부`
- 입력 특성: 타깃을 제외한 전체 수치형 특성
- 결측치: 각 특성의 중앙값으로 대체
- 학습/테스트: 75% / 25%
- random_state: 42

## 3. 모델 비교 결과

| 모델               |   Accuracy |   Precision |   Recall |     F1 |
|:-------------------|-----------:|------------:|---------:|-------:|
| LogisticRegression |     0.8282 |      0.6667 |   0.3529 | 0.4615 |
| DecisionTree       |     0.7975 |      0.5238 |   0.3235 | 0.4    |
| KNN                |     0.816  |      0.6429 |   0.2647 | 0.375  |
| RandomForest       |     0.8098 |      0.6364 |   0.2059 | 0.3111 |

## 4. 주요 특성
RandomForest 기준 상위 특성:
- 진동: 0.2000
- 온도: 0.1793
- 정비후경과일: 0.1614
- 누적가동시간: 0.1350
- 압력: 0.1214

## 5. 최종 결론 예시
제조설비 고장 예측 문제를 분류 모델로 해결했습니다. LogisticRegression, KNN, DecisionTree, RandomForest를 비교했으며 예시 실행에서는 LogisticRegression의 F1-score가 0.4615로 가장 높았습니다. RandomForest 기준 중요 특성으로는 진동, 온도, 정비후경과일 등이 확인되었습니다. 실제 적용 시에는 예측 오류, 특히 거짓 양성/거짓 음성이 업무에 미치는 영향을 함께 고려해야 합니다.
