Team 3 강사용 프로젝트 가이드
================================

[프로젝트]
제품 표면 패턴 판별

[교안 연결]
- 신경망 구조: Input, Dense, Weight, Bias, Activation, Loss
- 학습 제어: Epoch, Batch Size, Optimizer, Learning Rate, Dropout, EarlyStopping, History
- 데이터 구조: 표형 / 이미지 / 순차 데이터에 맞는 모델 선택

[핵심 지도 포인트]
- X.shape의 4개 축을 학생이 말로 설명하게 합니다.
- Conv2D의 filters가 출력 채널 수가 된다는 점을 확인합니다.
- MaxPooling2D 후 높이와 너비가 어떻게 변하는지 summary에서 찾게 합니다.
- Flatten 이전과 이후 shape 변화를 반드시 설명하게 합니다.

[공통 체크]
- 데이터 shape를 설명할 수 있는가?
- 출력층 활성화 함수와 Loss 조합이 문제 유형과 맞는가?
- Scaling을 Training Set 기준으로 적용했는가?
- validation 성능을 보고 학습 상태를 해석하는가?
- EarlyStopping의 monitor와 patience를 설명할 수 있는가?
- 최종 결과를 단순 점수뿐 아니라 업무/데이터 관점에서 설명하는가?

[시간 부족 시]
- 모델 구조 1~2개만 완성해도 됩니다.
- 학습곡선 + 핵심 성능 그래프를 우선합니다.
- 보고서는 2~3페이지 분량으로 간결하게 작성하도록 합니다.

[환경]
TensorFlow가 설치되지 않았다면 터미널에서 다음 명령을 사용할 수 있습니다.

pip install tensorflow

CPU 환경에서도 실행 가능하도록 데이터 크기와 모델 규모를 작게 구성했습니다.
